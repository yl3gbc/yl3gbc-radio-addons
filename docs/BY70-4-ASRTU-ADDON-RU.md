# Специализированный аддон BY70-4 для SONIKS

## Цель
Разрабатывается отдельное Linux-приложение для декодирования телеметрии спутника BY70-4 на базе открытого проекта ASRTU Series Receiver.

Цель — адаптировать декодер к Qt 6.12, собрать необходимые модули GNU Radio и реализовать поддержку BY70-4 как отдельный специализированный аддон для SONIKS.

## Сборка
Весь проект собирается только из исходного кода (SRC). Готовые бинарные файлы и заранее собранные пакеты не используются. Qt, GNU Radio, Boost и дополнительные модули собираются или подключаются как исходные компоненты.

## Возможности
Аддон должен:
- принимать записанный или живой сигнал BY70-4;
- выполнять демодуляцию BPSK 9600 и FEC-декодирование;
- извлекать телеметрические кадры;
- передавать живые декодированные данные в SONIKS/SatNOGS;
- отдельно отправлять телеметрию на сервер проекта BY70-4 через его протокол загрузки.

## Безопасность отправки
Отправка в SONIKS/SatNOGS и на сервер BY70-4 должна включаться независимо. Для офлайн-записей автоматическая отправка на серверы отключается, чтобы старые записи не считались живой телеметрией.

## Интеграция
Это не изменение ядра SONIKS, а отдельный специализированный аддон BY70-4, полностью собираемый из SRC.
