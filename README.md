# YL3GBC Radio Addons

Private addon repository for YL3GBC radio and satellite-station extensions.

Modules:
- journal
- monitor
- offline test
- SDRplay RSP1A integration

Original SONIKS source code is not included.

Git rule:
Every file must have its own separate commit.
One commit must never contain changes to more than one file.

GitHub is the authoritative copy of this addon project.
