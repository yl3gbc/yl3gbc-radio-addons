# YL3GBC Radio Addons

## English

Addon repository for YL3GBC radio and satellite-station extensions.

Modules:
- Journal
- Monitor
- Offline test
- SDRplay RSP1A integration

Original SONIKS source code is not included.

Git rule: every file must have its own separate commit.
One commit must never contain changes to more than one file.

## Русский

Репозиторий дополнений YL3GBC для радиолюбительской и спутниковой станции.

Модули:
- Журнал
- Монитор
- Офлайн-тест
- Интеграция SDRplay RSP1A

Исходный код SONIKS в этот репозиторий не включается.

Правило Git: каждый файл должен иметь отдельный коммит.
В одном коммите никогда не должно быть изменений более чем одного файла.
