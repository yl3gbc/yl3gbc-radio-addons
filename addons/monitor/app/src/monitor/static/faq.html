FAQ — SONIKS Monitor 0.1alfa

Почему время в UTC?

В наблюдениях SONIKS и на портале время всегда UTC — это стандарт радиолюбителей. Местное время в шапке — только для справки, для тех, кто не привык к UTC.

Меняет ли монитор что-нибудь в станции?

Нет. Код клиента SONIKS не изменён, монитор только читает данные станции. Единственное: в настройках дополнения указано не удалять данные наблюдений после выгрузки, чтобы пакеты, водопады и изображения оставались на диске станции.

Откуда берутся данные?

Наблюдения, пакеты, водопады и изображения — с диска станции. Сведения о станции, владелец, будущие задания и сравнение со станциями в сети — с портала sonik.space.

Что значит «Сегодня»?

Текущие сутки UTC, с 00:00:00 UTC. Например, в Москве (UTC+3 круглый год) это 03:00 по местному времени.

Что показывает «Мин. SNR с данными» в «Сигнал / Waterfall»?

Самый низкий SNR, при котором в этом режиме (модуляция и скорость) за последние 90 дней были декодированы данные. По нему видно, с какого уровня сигнала режим начинает декодироваться.

Почему у снимка написано «Изображение неполное»?

Файл изображения повреждён или неполный: например, во время пролёта не были приняты все пакеты, и у файла нет начала. Браузер его показать не может, но файл сохранён в архиве и входит в ZIP.

Когда создаётся ZIP-архив?

После окончания двухмесячного периода UTC. Если позже приходит снимок за уже закрытый период, ZIP этого периода создаётся заново.

Сколько хранятся данные?

Наблюдения в мониторе — 90 дней. Изображения и ZIP-архивы — бессрочно.

Что значит «Не подключено» у «Архива изображений»?

Папка для изображений на диске станции недоступна для записи. Изображения тогда не копируются, пока папка не будет подключена.

Как переключить язык?

Кнопками RU / EN в шапке. Выбор запоминается в браузере.

FAQ — SONIKS Monitor 0.1alfa

Why is the time in UTC?

In SONIKS observations and on the portal the time is always UTC — the radio amateur standard. The local time in the header is for reference only, for those not used to UTC.

Does the monitor change anything in the station?

No. The SONIKS client code is not changed; the monitor only reads the station's data. The one thing: the add-on settings tell the station not to delete observation data after upload, so that packets, waterfalls and images stay on the station disk.

Where does the data come from?

Observations, packets, waterfalls and images come from the station disk. Station details, owner, future jobs and comparison with stations on the network come from the sonik.space portal.

What does "Today" mean?

The current UTC day, from 00:00:00 UTC. For example, in Moscow (UTC+3 all year) that is 03:00 local time. Keep in mind that many countries switch between summer and winter time: there the local hour at which the UTC day starts changes twice a year.

What does "Min SNR with data" in "Signal / Waterfall" show?

The lowest SNR at which data was decoded in this mode (modulation and rate) over the last 90 days. It shows from which signal level the mode starts to decode.

Why does an image say "Incomplete image"?

The image file is damaged or incomplete: for example, not all packets were received during the pass and the file has no beginning. The browser cannot show it, but the file is kept in the archive and is included in the ZIP.

When is the ZIP archive made?

After a two-month UTC period ends. If an image for an already closed period arrives later, the ZIP for that period is made again.

How long is data kept?

Observations in the monitor — 90 days. Images and ZIP archives — forever.

What does "Not connected" on "Image archive" mean?

The image folder on the station disk is not writable. Images are not copied until the folder is connected.

How do I switch the language?

With the RU / EN buttons in the header. The choice is remembered in the browser.
